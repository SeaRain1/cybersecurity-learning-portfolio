# pwn.college Learning Logs



This directory documents the concepts and skills I learn while completing pwn.college challenges.



Because pwn.college asks users not to publish challenge write-ups or solutions, these learning logs intentionally omit:



- Flags, tokens, and other challenge secrets

- Challenge-specific solution commands

- Step-by-step walkthroughs

- Provided challenge files or code

- Screenshots or explanations that reveal solutions



Each entry may identify the challenge I completed, but it focuses only on the general technical concepts I learned. All demonstrations use original examples unrelated to the challenge.



These entries are learning notes, not pwn.college walkthroughs.
